## 1. 질문과 답

**질문**: 1-스텝 목적함수 τ의 "직전 액션이 0이면 액션 0이 상수 0.65로 최적"이라는 고정점
(E00 §8)이, 계획 지평을 L 스텝으로 늘린 τ_L 완전열거에서 해소되는가? 해소된다면 임계 L\*는?

**답**: **해소된다. L\* = 2.** 층화 부표본 270 시나리오 전부(예외 0)에서

- **L = 1**: 270/270 월류, 액션 0 고착률 1.000, max_level 10.00 (E00 재현).
- **L = 2**: **0/270 월류**, 고착률 ≈ 0.54, max_level ≈ 9.2.
- L ≥ 3: 월류 0 유지, max_level 단조 감소 (L3 ≈ 7.96, L4 ≈ 7.44, L5 ≈ 7.14).

γ_h ∈ {1.0, 0.9}, 유입 예측 (A) 완전예지 / (B) 지속성 **네 조합 모두 L\* = 2**. 지속시간
9구간(60~1440분) 전부에서 동일 — **고정점과 그 해소는 지속시간과 무관한 구조적 성질**이다.

이로써 R1-1·R4-1에 대한 논증이 완결된다:

> **1-스텝 목적함수의 실패(액션 0 고착 → 월류)는 보상 설계 결함이 아니라 계획 지평의
> 한계이며, L ≥ 2에서 사라진다. 그리고 그 지평에서 후보 공간은 6^L로 증가하므로
> (L=3: 216, L=5: 7,776) 완전열거는 곧 비현실적이 되고, 메타휴리스틱이 필요해진다.**

**(A) 완전예지와 (B) 지속성의 차이는 무시할 수준이다** — L≥2에서 mean max_level 차이

매끄러워, 1-스텝 앞 유입을 평평하게 외삽해도 계획이 거의 바뀌지 않는다. **즉 완전예지가
숨은 이점을 제공하지 않는다** — L\*=2 결론은 예보 품질에 의존하지 않는다. (응답서에서
"완전예지는 실제 배치에서 달성 불가능한 상한이나, 이 문제에서는 지속성 근사와 사실상
동일한 성능을 준다"로 서술.)

### 2.3 γ_h 민감도

γ_h=1.0이 0.9보다 약간 나은 제어(더 낮은 peak, 더 이른 기동)를 주지만, **둘 다 L=2에서
월류가 사라진다**. 해소 임계는 γ_h에 무관.

### 2.4 L=2는 월류만 없앨 뿐 — 좋은 제어는 L ≥ 4

L=2에서 고착률이 0.54로 여전히 높고, 컨트롤러는 수위가 ≈ 9.2 m까지 오르기를 기다렸다가
액션 5로 급대응한다(첫 기동 중앙값 스텝 63.5). L이 커질수록 더 일찍(L5: 스텝 43.5),
더 부드럽게 대응해 peak가 낮아진다(L5: 7.14). **해석상 두 임계가 있다**: 월류 제거
임계 L\*_flood = 2, 능동적 수위 제어 임계 L\*_control ≈ 4~5. 응답서에는 전자를 "고정점
해소"의 답으로, 후자를 "지평이 길수록 제어가 개선된다"로 구분해 쓴다.

## 3. 왜 L=2에서 전환이 일어나는가 — 스텝별 τ_L 실측

**시나리오** `20yr_1440m_h1149` (748 결정), γ_h=1.0, 완전예지.
전체 표: `results/E04_enum/horizon_probe_20yr_1440m_h1149.csv`.

L=1 고정점 궤적(전 스텝 액션 0)을 따라가며, 선택된 결정 스텝에서 각 L의

**모든 스텝에서 L=1은 액션 0을 고른다** — level 10.0(월류 중)에서도. 스텝 374의
τ_1 per action = `[0.650, 0.609, 0.568, 0.527, 0.514, 0.500]` (E00 §2 표와 정확히 일치):
액션 0만 0.65, 나머지 전부 그 미만 → 1-스텝 argmax는 절대 펌프를 켜지 않는다.

### 3.1 항 분해 (level 10.0, 저류 충분, γ_h=1.0)

액션 5: pump_rate = Σpumpq = 640, attempt = 1280, actual_outflow = 1280 (저류 충분),
excess = 0.

| 전이 | vol_reward | w1·vr (0.25) | act_reward | w2·ar (0.40) | w3·energy (0.25·0) | **τ** |
|---|---|---|---|---|---|---|
| 0→5 (k=0) | (1280/640)·(10/10) = 2.0 | 0.50 | 1−5/5 = 0 | 0 | 0 | **0.50** |
| 5→5 (k≥1) | 2.0 | 0.50 | 1 | 0.40 | 0 | **0.90** |
| 0→0 | 0 (actual=0) | 0 | 1 | 0.40 | 0.25 | **0.65** |

- **"전부 0"**: τ_L = 0.65·L  → 1: 0.65, 2: 1.30, 3: 1.95, 4: 2.60, 5: 3.25
- **"0→5 후 5 유지"**: τ_L = 0.50 + 0.90·(L−1)  → 1: 0.50, 2: **1.40**, 3: 2.30, 4: 3.20, 5: 4.10
- **교차 조건**: 0.50 + 0.90(L−1) > 0.65L  ⇔  0.25L > 0.40  ⇔  **L ≥ 2**

즉 **일회성 스위칭 비용(0.65 → 0.50, 즉 −0.15)이 두 번째 스텝부터의 유지 이득
(0.90 vs 0.65, 즉 +0.25)으로 상각되는 지점이 정확히 L = 2**다. 스텝 374의 실측
τ_L(best) 값(1.4000 / 2.3000 / 3.2000 / 4.1000)이 이 산식과 소수점까지 일치한다.

### 3.2 저류가 덜 찼을 때는 L\* = 3

스텝 155 (level 8.15): `vol_reward(5) = (actual/640)·(8.15/10)`이고 actual이 가용 저류량에
묶여 작다 → τ_1(5|prev 0) = 0.407 (표). 스위칭 이득이 작아 L=2로는 상각이 안 되고
(Δ = +0.0000, 동점 → 액션 0 유지), **L=3에서 처음 전환**(Δ = +0.0476). 즉 **국소적
L\*는 저류 수위에 의존**한다 — 저류가 높을수록(펌핑이 즉시 생산적일수록) 더 짧은 지평으로
탈출한다. receding-horizon 컨트롤러는 "현재 수위 기준으로 펌핑이 지평 안에서 이득이
되는 순간" 탈출하며, 그 순간은 월류보다 훨씬 이르다 → L≥2에서 월류가 원천 차단된다.

### 3.3 목적함수에 월류 벌점항이 없다는 사실은 그대로다

τ_L("전부 0")은 저류가 16,000㎥를 넘겨 침수해도 **항상 정확히 0.65·L**이다(액션 0에서
vol_reward=0, 월류 벌점항 부재). 그럼에도 고정점이 깨지는 이유는 τ_L이 침수를 **직접**
벌해서가 아니라, **저류가 차면 펌핑의 vol_reward가 커져 "스위칭+유지"의 누적 τ_L이
"전부 0"의 0.65·L을 넘어서기** 때문이다. 이는 E9(보상–목적 상관)와 연결되는 관찰이다 —
다단계 지평은 월류항 없이도 실무적으로 월류를 막지만, 목적함수에 명시적 월류항을 넣으면
L\*가 더 작아지고 peak가 더 낮아질 여지가 있다(E9에서 검토).

## 4. E4-b 설계에 대한 함의

1. **L 집합**: 계획서 {1, 3, 5}에 **L = 2를 추가**한다 — 해소 임계가 정확히 2이므로
   {1, 2, 3, 5}가 논증에 필수. (L=4는 선택.)
2. **γ_h**: 1.0을 주값으로. 0.9는 해소 결론을 바꾸지 않으므로 민감도 각주로 충분.
3. **유입 예측**: (B) 지속성을 주 결과로, (A) 완전예지는 참조. §2.2에서 둘의 차이가
   무시할 수준임이 이미 확인됨 — E4-b에서도 같은 결론이 예상되나 재확인.
4. **demonstration 생성**: ENUM-L (L∈{3,5})로 학습용 시연을 만든다. §2.4에 따라 L을
   키우면 제어가 부드러워지므로, L=3 시연과 L=5 시연으로 학습한 DDQN의 차이가
   유의미할 수 있다.
5. **스케일링 그래프**: E4-a에서 이미 L=1 결정시간(ENUM 0.039 ms / PSO 1.43 ms /
   GA 20.0 ms)을 측정했다. E4-b에서 L∈{2,3,5}의 ENUM-L 결정시간(6^L 완전열거)과
   GA-L/PSO-L(정수 L-지놈) 결정시간을 더해 로그-로그 그래프를 그린다.
   > **취소(2026-08-30)**: 이 항목이 제안했던 "순수 6^L 스칼라 완전열거를 별도
   > 구현해 측정"은 **취소한다.** 열거 baseline만 느린(미배치) 구현으로 바꾸고
   > GA-L/PSO-L은 그대로 두면 불공정 비교가 된다 — 실제로 `enum_l_deploy.py`로
   > 그렇게 측정해 "실용 열거 상한 L=7"을 냈으나(`HORIZON_SATURATION.md`), 벡터화
   > 기준 상한은 L≈12로 약 3,200배 차이가 났다. 올바른 방법은 ENUM-L·GA-L·PSO-L
   > **셋 다** 미배치·벡터화 양쪽에서 재는 것이며, 그 결과는
   > `docs/E04E_REPORT.md` Task A 참조.

## 5. 서술 원칙 (응답서·원고 작성 시 필수)

**이 결과(E4-§3)는 E4-a·E4-b와 반드시 묶어서 제시한다.** 다음 두 문장은 **함께** 써야
하며, 앞 문장만 떼어내면 논문 방법론 전체가 무의미해진다:

> (i) 6개 행동공간의 1-스텝 목적함수에 대해 GA/PSO는 완전열거의 느린 근사일 뿐이며
>     산출 정책이 동일하다 (E4-a: GA 일치율 100 %, GA-only ≡ PSO-only ≡ ENUM).
> (ii) 그러나 1-스텝 목적함수 자체가 부족하다 (L=1에서 270/270 월류). 계획 지평을
>      L ≥ 2로 늘리면 이 실패가 사라지고, 그 지평에서 후보 공간이 6^L로 커져
>      완전열거가 비현실적이 되므로 메타휴리스틱이 필요해진다 (E4-§3, E4-b).

**(i)만 인용하면** "그럼 열거만 하면 되지 않느냐 → 방법론 불필요"로 귀결된다.
**(ii)와 함께** 제시해야 "1-스텝에서는 열거로 충분하나, 이 연구가 목표하는 다단계
지평·demonstration 자동생성에서는 메타휴리스틱이 필연"이라는 완결된 논거가 된다.
계획서 E4 "행동공간 6개에 대한 서술 원칙" 절의 응답서 골격을 따를 것.
