# 시드 수준 통계 (2026-09-11)

외부 검토 지적 (a) "n=13,500을 독립 표본으로 다룬 것은
의사반복(pseudoreplication)에 해당한다"에 대응해, 기존 산출물
(`results/E03_seeds/`, `results/E05_ablation/`)로 시드 수준 통계를
계산한 결과다. **재학습은 수행하지 않았다.** 해석·옹호 없이 사실·
숫자만 기록한다. 기존 파일은 읽기만 했고 수정하지 않았다.

## 방법

- **U(π) 계산**: 원자료(`test_metrics.csv`)에 U 열이 없어 항등식으로
  재계산했다 — `U = (100×n_intervals_100 + 170×n_intervals_170) / 640`
  (이 항등식은 `results/summary/PUMP_USE_INDEX.md` §0에서 코드
  대조로 이미 확인된 것을 재사용, 신규 검증 아님).
- **시드평균 차(1-1)**: 모델 A의 시드 s 평균 − 모델 B의 시드 s 평균,
  s=1..5.
- **시드수준 대응차 평균(1-2)**: 시나리오 단위 대응차(A−B, 같은
  시드·같은 시나리오)를 시드별로 먼저 평균 → 5개 값. **이 값은
  대수적으로 1-1의 "시드평균 차"와 동일하다**(합의 선형성 —
  mean(A)−mean(B) = mean(A−B), 같은 2,700개 시나리오에 대해 두 모델이
  1:1 대응하므로). 따라서 하나의 표로 병합해 제시한다(요청하신
  "같은 표에 나란히 제시" 요건 충족).
- **동일방향 시드 수**: 5개 시드평균차의 부호를, 전체(2,700×5=13,500)
  대응차 평균의 부호와 비교해 일치하는 시드 수를 센다.
- **시드수준 Wilcoxon**: n=5(시드평균차 5개)에 대한 부호순위검정.
  **n=5에서는 양측검정 최소 달성 가능 p=2/32=0.0625**이며(모든 5개
  부호가 동일할 때), Holm 보정 여부와 무관하게 이 표본크기에서는
  유의성에 구조적으로 도달할 수 없는 경우가 있다 — 계산에 사용된
  `scipy.stats.wilcoxon`(정확검정, n≤25)의 결과를 그대로 기재한다.
- **시나리오수준**: 기존 관례(예: `E05_stage1_tests.csv`)와 동일하게
  n=13,500(2,700 시나리오×5시드)에 대한 Wilcoxon과 Cliff's δ.

표본크기로는 판별 불가"를 의미한다 — 판단은 하지 않고 수치만
보고).**

GA-only,PSO-only}/seed{1..5}/test_metrics.csv`,
`results/E05_ablation/{A0,A1}/seed{1..5}/test_metrics.csv`이며,
전부 기존 산출물이다(신규 실행 없음). 계산 스크립트는 이 저장소에

/`SEED_LEVEL_E5_full.csv`가 재현 가능한 전체 원시 결과를 담고
