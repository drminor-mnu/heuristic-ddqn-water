# R4-11 — Table 8 수치 오류 확인

**리뷰어 지적**: "Verify the numerical values in the result tables,
particularly the apparently identical entries in Table 8 for regular
DDQN at 120 min and GA-guided DDQN at 60 min."

**중요한 전제 확인(먼저)**: Table 8(및 Table 6~10 전체)은 원고 §3.1의
"exploratory comparison" — **2기준 Regular DDQN**(가중치
`w=[0.5,0.5,0,0]`, 최고수위+스위칭만) **vs 4기준 GA-guided DDQN**
비교다(`docs/manuscript_outline.md` Table 6·7 제목, `docs/CONTEXT.md`
14행). 이는 **E3 v2가 재생성한 Table 11~16(§3.3, 5모델 전부 4기준 동일
가중치 비교)과 완전히 다른 실험**이다 — E3 v2는 이 2기준 Regular
설정을 학습한 적이 없다. 따라서 사용자 지시의 전제("E3 v2로 표를
재생성했으므로 현재 값을 확인하면 답할 수 있다")는 **Table 6~10에는
적용되지 않는다** — E3 v2 데이터로는 Table 8을 직접 검증할 수 없다.
E1(전체 표 재생성) 취소와는 별개로, 애초에 E0~E13 어떤 실험도 이 2기준
Regular 설정을 재실행한 적이 없다(사실만 기록, 판단하지 않음).

## 판정

**우연의 일치가 아니라 데이터 오염(계산/전사 오류)이다.**

- 원고 Table 8에 인쇄된 값 `130.32, 141.26, 145.4, 151.08, 155.68,
  157.26`은 **Regular/60min**(위 1열, 171.3 등과 정확히 일치 확인됨),
  **Regular/120min**, **GA-guided/120min** 세 행에 **동일하게** 등장한다.
- Regular/120min의 **실제 값은 260.28~260.52**이며 원고 인쇄값과
  전혀 다르다 — **Regular/120min 행이 잘못된 값으로 대체됐다는 것은
  확정적 오류다.**
- 130.32는 우연히 Table 13의 다른 셀 값과 같지만 나머지 값들은
  다르므로 Table 13에서 통째로 복사된 것도 아니다.
- **GA-guided/60min·GA-guided/120min이 실제로 어떤 값이어야 하는지는
  확인 불가능하다** — `docs/RESULTS_PROVENANCE.md`의 "핵심 발견"
  절이 이미 규명한 대로, 이 2기준-vs-4기준 비교의 GA-guided 원본 raw
  파일은 저장소 어디에도 남아있지 않다(후보 파일 전부 대조했으나
  불일치, 상세는 그 문서 참조). 즉 **오염의 정확한 경로(어느 값이
  어디서 복사됐는지)는 특정되지 않으며, Regular/120min 하나만 확정적
  오류로 판정 가능하고 나머지 두 행(GA-guided 60/120min)은 오류인지
  아닌지조차 검증할 근거가 없다.**
