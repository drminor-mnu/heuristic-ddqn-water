**0을 지나는 구간**: w1=0.40(ρ=−0.2221)과 w1=0.45(ρ=+0.2090) 사이. 두
측정점을 선형보간하면 영점은 **w1≈0.4258**. **채택 가중치 w1=0.40은 이
구간의 음(−) 쪽 끝, 영점 바로 직전(약 0.026 차이)에 위치**한다 —
측정된 그리드 점 중 아직 부호가 반전되지 않은 마지막 지점.

## 3. E4-f Task C와의 대조 (사실 수준, 해석 없음)

| | E4-f Task C | 이번 E9 결과 |
|---|---|---|
| 대상 쌍 | cum_tau_L(L-스텝 lookahead 하 휴리스틱 1-step 목적함수 누적치) vs max_level | Σr(실제 누적 보상, 학습된 정책과 무관하게 매 스텝 보상의 합) vs max_level |
| 조작 변수 | lookahead 길이 L(1→8) | 보상 가중치 w1(0.20→0.50) |
| 관찰된 패턴 | cum_tau_L은 L에 대해 **항상 단조 증가**(수학적으로 증명됨)하지만, max_level은 L≥3부터 **악화 비율 65.6~100%**(다수 시나리오에서 "τ_L은 개선되는데 실제 목표는 나빠짐") | ρ(Σr, max_level)이 w1=0.27의 −0.72(reward 높을수록 수위 낮음 = 정합)에서 w1=0.50의 +0.29(reward 높을수록 수위 높음 = 불일치)로 **부호 자체가 반전** |
| 공통점(사실만) | 둘 다 "보상/목적함수 계열의 대리 지표"와 "실제 목표(max_level)" 사이의 관계가, 대리 지표를 만드는 파라미터(L 또는 w1)를 바꾸면 **정합에서 비정합으로 바뀌는 영역이 존재**함을 각자의 조작 변수 축에서 보여준다 |
| 차이점(사실만) | Task C는 같은 가중치 하에서 **lookahead 깊이**를 바꾼 것, 이번 결과는 같은 lookahead(1-step 보상) 하에서 **가중치 자체**를 바꾼 것 — 서로 다른 축의 실험이며 직접 비교 검증은 아니다 |

## 4. 데이터/방법 한계

- §2·§3의 w1 스윕 데이터는 **GA/PSO-only(휴리스틱 단독) 평가**이며 학습된
  DDQN 정책의 결과가 아니다 — §1의 pooled/모델별 상관(E3 v2 원본 5모델)과는
  다른 데이터 소스다.
- w1 그리드는 10개 점(0.20~0.50, 균일 간격 아님)뿐이며, 영점 위치(≈0.4258)는
  인접 두 점의 **선형 보간**이지 실측값이 아니다.
- D(dry-running)의 w1 그리드는 3개 유효점뿐이라 신뢰도가 낮다.
