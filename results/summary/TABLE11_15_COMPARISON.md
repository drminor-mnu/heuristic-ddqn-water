# Table 11~15 원고 값 vs 재생성 값 — 셀 단위 대조

원고(`docs/response/MANUSCRIPT_TEXT.md`)의 Table 11~15 값과 E3 v2
재생성 값(`results/summary/E03_table_*.csv`, 5시드 평균)을 (지속시간
9×재현기간 6×모델 5) 셀 단위로 대조한다. 해석·옹호 없이 사실·숫자만
기록한다.

## 0. 대조 범위

5개 표 × 9지속시간 × 6재현기간 = **270개 (표,지속시간,재현기간)
그룹**, 그룹당 5모델 값이 있어 **1,350개 개별 셀** 비교.

**지속시간이 길수록 차이가 단조 증가한다**(60분 2.68 → 1440분

반드시 "긴 지속시간에서 재현이 더 부정확하다"는 뜻은 아니다(지표
정의상 누적값이 커지는 효과가 섞여 있음) — 사실만 기록, 원인 판단은

### 3.3 절대차의 지속시간 의존성 — 정규화(상대 오차) 확인

§3.1의 절대차 증가(23배)에는 n_switches/n_intervals류 누적 지표의
"지속시간이 길수록 값 자체가 커지는" 구조적 효과가 섞여 있을 수
있다. 상대 오차(|재생성−원고|/원고)로 다시 계산해 이 효과를
분리한다. 계산: `/tmp/rel_err_detail.csv`(1,350행), 원고값이 0에
가까운 셀(|원고|<0.05)은 분모가 0에 가까워 상대 오차가 발산하므로
**평균(mean)은 불안정하고 중앙값(median)이 더 대표적**이다 — 아래
표에 "원고값<0.05인 셀 수"를 함께 표기해 이 불안정 구간을
식별한다.

**표별 판정**:
- Table 12(n_switches): 상대오차 중앙값도 26.6%→59.7%로 지속시간에

- Table 13(n_intervals_100): 상대오차 중앙값 5.2%→24.0%로 증가하나
  증가폭(약 4.6배)이 절대차 증가폭보다 작음 — 누적 효과가 상당 부분
  기여했음을 시사(사실만 기록, 원인 판단 아님).
- Table 14(n_intervals_170): 원고값 0에 가까운 셀이 지속시간과 함께
  급증해(0→25/54) 상대오차가 신뢰할 수 있는 지표가 아니게 됨 —
  이 표는 상대오차로 지속시간 의존성을 판단하기 부적절하다.
  절대차 기준으로는 §2.2·§3.1 참조.
- Table 15(n_dryrun_proxy): 상대오차 중앙값이 지속시간에 따라
  뚜렷한 단조 경향을 보이지 않는다(60분 90.0% → 1440분 79.1%,
  중간에 41~98% 사이를 오르내림) — 원고값<0.05 셀이 전 지속시간에
  걸쳐 고르게 존재(6~12개)해 상대오차 자체가 원래 잡음이 크다.

**어느 쪽이 지속시간과 관련되는가(요약)**: 절대차는 5개 표
전부에서 지속시간에 따라 뚜렷이 증가한다(§3.1). 상대오차는
Table 11·12·13에서는 지속시간에 따라 증가하는 경향이 남아있으나
증가폭이 절대차보다 작고(Table 11: 2.3배, Table 13: 4.6배 vs
전체 절대차 23배), Table 14·15는 원고값이 0에 가까운 셀이 많아
상대오차 계산 자체가 불안정하다.

## 4. 요약 (판단 없음)

- 270개 그룹 중 91.5%에서 5모델 순위 자체가 원고와 다르다.
- 절대차는 표마다 스케일이 크게 다르며(§2.2), Table 13이 최대
  절대차(726.524)를 보인다.
- 절대차는 지속시간이 길수록 커지고(§3.1), 재현기간별 차이는
  평평하다(§3.2).
- 상대 오차(정규화)로 다시 봐도 Table 11·12·13은 지속시간에 따라
  증가하는 경향이 남아있다(§3.3) — 다만 증가폭은 절대차(23배)보다
  작다(Table 11 약 2.3배, Table 13 약 4.6배). Table 14·15는 원고값이
  0에 가까운 셀이 많아 상대오차 계산 자체가 불안정하다(§3.3).
- 원인(코드 재현성, 데이터 버전, 가중치 등)은 조사하지 않았다 —
  `docs/response/SECTION_3_1_REGENERATION.md`/`RESULTS_PROVENANCE.md`에
  이미 기록된 "원본 raw 소실, 재현 불가" 사실과 결이 같다.
