# E10 — 실시간 운용 여유율 (R2-2)

**질문(R2-2)**: 휴리스틱 단독 방식(GA-only/PSO-only)의 추가 계산비용이
실사용을 제약할 정도인가? 결정 간격(2분=120초)과 결정당 소요시간을
비교해 정량적으로 답한다.

**하드웨어**: CPU 13th Gen Intel Core i9-13900KF(24코어/32스레드), GPU
NVIDIA RTX 3080 Ti(12GB), RAM 94GB(`results/_log/ENVIRONMENT.json`).

## 결정당 소요시간 (기준: (c) — 신경망 forward pass + 상태 전처리 + 환경 step 오버헤드, SWMM 미포함)

측정 범위 (a)~(d)의 정의는 `E10_unified_table.md` 참조. **(c)를 기본값으로
쓰는 이유**: 실제 결정 루프가 매 스텝 실행하는 계산 전부이며, SWMM은
스텝마다가 아니라 에피소드당 1회만 발생하기 때문(아래 (d) 별도 표기).

| 모델 | 결정당 시간(c 기준) | 결정 간격(120,000 ms)과의 비교 |
|---|---|---|
| Regular (DDQN) | **0.278 ms** | 120,000 ms 중 0.278 ms 사용(배수로는 약 432,000배 여유) |
| GA-guided (DDQN, 평가 시 가이던스 미개입) | **0.239 ms** | 120,000 ms 중 0.239 ms 사용(약 502,000배 여유) |
| PSO-guided (DDQN, 평가 시 가이던스 미개입) | **0.264 ms** | 120,000 ms 중 0.264 ms 사용(약 455,000배 여유) |
| GA-only(미분리, 총시간 기준) | **21.398 ms** | 120,000 ms 중 21.398 ms 사용(약 5,600배 여유) |
| PSO-only(미분리, 총시간 기준) | **21.792 ms** | 120,000 ms 중 21.792 ms 사용(약 5,500배 여유) |

사용 — `E10_unified_table.md` "세부 분해" 참조.)

## 결론(사실만)

모든 모델의 결정당 시간이 120,000 ms의 결정 간격에 대해 1 ms 미만이다
(DDQN 0.24~0.28 ms, GA/PSO-only 21.4~21.8 ms). 배수로 환산하면 DDQN은
약 430,000~500,000배, GA/PSO-only는 약 5,500~5,600배의 여유가 있으나,
**이 배수 자체보다 절대값이 결정 간격(120초) 대비 극히 작다는 사실이
핵심이다.**

이 수치만 보면 R2-2가 우려한 "실시간 제약 위반"은 관측되지 않는다.
계획서 E10이 제시한 대응 방향(제안 기법의 이점을 "실시간성" 대신
"대규모 시나리오 배치 평가·다지점 확장·저사양 현장 하드웨어"로
재조정)은 이번 측정 결과와 상충하지 않는다 — 다만 그 재조정 서술 자체의
적정성은 응답서 작성 시점의 판단이며 이 문서의 범위 밖이다.

**측정 조건의 한계**: 이번 측정은 54개 시나리오(전체 2,700개의 부표본),
1개 시드(seed1), 신가중치 기준이다. GA/PSO 탐색 시간은 상태·시나리오
난이도에 따라 변동 가능하므로(조기종료 patience=10에 따라 세대 수가
가변적), 이 평균값이 최악의 경우(worst case)를 대표하지는 않는다.

## 원고 Table 5 값(257,224.97 s / 256,591.19 s)에 대한 분석 — 기록 목적, 응답서에는 미사용

아래는 **이 세션의 분석 기록**이며, 검증 불가능한 추측이라 위 응답서
서술에는 포함하지 않는다. 원고 Table 5의 Regular 257,224.97초·GA-guided
256,591.19초는 각각 약 **71.45시간·71.28시간**에 해당한다. 원본 실행
로그·raw 산출물이 소실되어(`docs/RESULTS_PROVENANCE.md`) 무엇을 측정한
값인지 이 세션에서 확정하지 못했다.

- **관찰된 사실(추정 아님)**: 두 값의 차이는 0.25%(257,224.97 vs
  256,591.19)에 불과해 **거의 동일**하다. 반면 이번 세션이 실측한 E3 v2
  학습시간(`run_meta.json`의 `elapsed_train_s`)은 Regular 2.84시간, GA-guided
  5.23시간으로 **1.84배 차이**난다(GA 탐색 오버헤드 때문). Regular와
  GA-guided는 구조적으로 다른 학습 과정(GA 시연 탐색 유무)을 거치므로,
  **순수 학습시간이라면 이렇게 거의 같은 값이 나오기 어렵다**는 것이
  이번 세션이 확인한 사실이다.
- **추정 1(가장 가능성 있어 보임, 검증 안 됨)**: Table 5 값이 두 모델
  모두에서 거의 같다는 점은, 모델 종류와 무관하게 공통으로 발생하는
  비용(예: 전체 테스트/학습 시나리오에 대한 SWMM 시뮬레이션 총합)이

  비용(에피소드당 약 0.16초)을 그대로 적용하면 257,225초는 약 160만
  시나리오에 해당해, 현재 데이터 규모(6,696개)로는 설명되지 않는다 —
  **하드웨어·SWMM 버전·측정 방식이 달랐을 가능성을 배제할 수 없어
