# 행동공간(6개 조합) 근거

**대응 리뷰어**: R1-3 (계획서 E11). 부차적으로 R4-8(일반화 주장 완화).
**작성일**: 2026-08-29
**성격**: 근거 서술 문서. 추가 학습 불필요. 이 문서가 완성되면 R1-3은 종결된다.

---

## R1-3의 질문

> 왜 100 m³/min 1대 + 170 m³/min 1대 같은 조합이 배제되는가? 제약의 근거(hydraulic / electrical / mechanical / operational)가 없다면, 제한된 행동공간이 제어 문제를 인위적으로 단순화한 것 아닌가?

---

## 1. 6개 조합은 대상 시설의 현행 운영 조합이다

가산배수지에서 **현재 실제로 사용 중인 6개 운영 조합**을 그대로 행동공간으로 채택했다. 연구 편의를 위해 축소한 집합이 아니라 **관측된 사실**이다. 선행 논문(Joo, Jeong & Kang, 2024, *Water* 16(3398)) 역시 동일한 6조합을 사용했다.

## 2. 6개 조합은 기동 순서 규칙에서 구조적으로 도출된다

선행 논문 Table 4의 규칙기반 운영표는 **누적 사다리(cumulative ladder)** 구조를 갖는다.

| 수위 상승 시 | 동작 | 조합 (100㎥, 170㎥) |
|---|---|---|
| ~6.2 m 미만 | 전량 정지 | (0, 0) |
| 6.2 m | 100㎥ 1대 기동 | (1, 0) |
| 6.3 m | 100㎥ 2대 | (2, 0) |
| 6.4 m | 100㎥ 3대 | (3, 0) |
| 6.5 m | + 170㎥ 1대 | (3, 1) |
| 6.6 m | + 170㎥ 2대 (전량) | (3, 2) |

(하강 시 5.9 → 5.5 m에서 역순 정지, 전량 정지는 5.5 m.)

**핵심**: 100 m³/min 펌프 3대가 모두 기동된 뒤에야 170 m³/min이 투입된다. 실제 사용 조합 (0,0) (1,0) (2,0) (3,0) (3,1) (3,2)가 이 순서와 정확히 일치한다.

## 3. 조합 수 계산

펌프는 물리적으로 5대(100 m³/min 3대 + 170 m³/min 2대)지만, **동일 용량 펌프는 교환 가능**하므로 수리적으로 구별되는 조합은 2⁵ = 32가 아니라

> **(3 + 1) × (2 + 1) = 12** (100㎥ 가동 대수 0~3 × 170㎥ 가동 대수 0~2)

이다. 선행 논문도 12로 기술한다. **응답서·원고에서 `2⁵ = 32`로 쓰지 말 것.**

## 4. 12개 중 제외된 6개 — 전부 누적 사다리 위반

| 조합 (100㎥, 170㎥) | 사용 여부 | 사다리 구조 부합 여부 |
|---|---|---|
| (0, 0) | 사용 | 부합 (전량 정지) |
| (1, 0) | 사용 | 부합 |
| (2, 0) | 사용 | 부합 |
| (3, 0) | 사용 | 부합 |
| (3, 1) | 사용 | 부합 |
| (3, 2) | 사용 | 부합 (전량 가동) |
| **(0, 1)** | 미사용 | 100㎥ 0대인데 170㎥ 운전 |
| **(0, 2)** | 미사용 | 100㎥ 0대인데 170㎥ 2대 운전 |
| **(1, 1)** | 미사용 | 100㎥ 미완전(1/3) 기동 상태에서 170㎥ 운전 |
| **(1, 2)** | 미사용 | 100㎥ 미완전(1/3) 기동 상태에서 170㎥ 2대 운전 |
| **(2, 1)** | 미사용 | 100㎥ 미완전(2/3) 기동 상태에서 170㎥ 운전 |
| **(2, 2)** | 미사용 | 100㎥ 미완전(2/3) 기동 상태에서 170㎥ 2대 운전 |

제외된 6개는 **예외 없이 "100 m³/min 펌프가 3대 모두 기동되지 않은 상태에서 170 m³/min 펌프가 운전되는" 경우**다. 누적 사다리 규칙이 조합 집합을 결정한다.

## 5. 선행 연구와의 비교 가능성

규칙기반 · 선행 DDQN(Joo et al. 2024) · 본 연구를 동일 조건에서 비교하려면 행동공간이 같아야 한다. 선행 논문이 6조합을 사용했으므로 본 연구도 동일하게 유지한다.

---

## 제약의 성격에 대한 서술 방침 (확정)

R1은 제약이 "hydraulic, electrical, mechanical, or operational" 중 무엇인지 명시하라고 요구했다. **본 연구는 운영기관의 내부 자료에 접근할 수 없으므로 제약의 물리적 원인을 특정하지 않는다.** 대신 아래 범위로 한정한다.

> 본 연구에서 사용한 6개 조합은 대상 시설의 현행 운영 규정에 따른 것이며, 본 연구는 이를 제어 문제의 제약 조건으로 수용하였다.

요지 세 가지:
1. 6조합은 **관측된 사실**(현행 운영 규정)이지 저자의 설계 선택이 아니다.
2. 그 규정의 물리적·전기적 원인 규명은 **본 연구의 범위 밖**이며 자료 접근이 불가능하다.
3. 따라서 제어 문제의 **주어진 제약**으로 수용한다.

**하지 말 것**: 흡입수위, 기동전류, 토출관로 구성 등을 추정으로 언급하지 않는다. 근거 없이 물리적 원인을 서술하면 R1이 재차 근거를 요구하게 되고 이번에는 답할 수 없다. "확인할 수 없어 수용했다"가 "아마 이런 이유일 것이다"보다 안전하다.

**보강 가능**: 원인은 특정하지 않되, 규정의 **구조**는 위 §2·§4처럼 기술할 수 있다. 이는 선행 논문 Table 4라는 공개 근거에서 직접 도출되므로 추정이 아니다. "왜 그런 규정인지"는 답하지 않지만 "규정이 어떤 구조인지"는 명확히 보일 수 있고, 이것만으로 "임의로 축소한 행동공간"이라는 의심은 해소된다.

## Discussion(3.5절)에 추가할 한계 문장

> 행동공간은 대상 시설의 현행 운영 규정을 따랐으므로, 규정이 다른 시설이나 규정 자체의 완화가 가능한 경우에는 더 넓은 조합 집합에서 추가적인 성능 개선 여지가 있을 수 있다.

R4-8(일반화 주장 완화)에도 함께 대응된다.
