## Task C — τ와 실제 목표의 괴리 (R1-4)

### 1. cum_tau_L 단조성 검증

**정의**: `cum_tau_L(시나리오) = Σ_t τ_L(그 결정시점에서 ENUM-L이 고른 최적 시퀀스)`.

**수학적 증명(사전 확인)**: 임의의 L-시퀀스 끝에 액션 0을 이어붙이면 증분
`γ_h^L · τ(0|도달상태)`가 반드시 **엄격히 양수**다 — τ(0)의 세 비음수항 중
`w3·energy_reward(0) = w3·1 = w3 > 0`(신·구가중치 모두 w3=0.25)이 항상 존재하고
vol_reward·act_reward도 ≥0이며 액션 0은 초과펌핑(excess) 페널티가 절대 발동하지
않기 때문이다. 따라서 `ENUM_{L+1}(최적값) ≥ ENUM_L(최적 시퀀스) + γ_h^L·τ(0) >
ENUM_L(최적값)`이 **모든 상태에서** 성립 — 완전열거이므로 cum_tau_L은 L에 대해
반드시 엄격히 증가해야 한다.

**실측**: **270개 시나리오 전부(100%)에서 cum_tau_L이 사용 가능한 전 L 구간에서
엄격히 증가**(위반 0건). 버그 없음 — 증명과 정확히 일치.

**항 분해**: 액션 0을 유지하면 `w2·act_reward(0→0)=0.25`(w2=0.25) +
`w3·energy_reward=0.25` = **상수 0.500**. 처음 펌프를 켜는 순간(0→1)은
`act_reward`가 즉시 하락(1→0.2 근처, 전환 페널티)해 `τ≈0.48`로 **유지보다 낮다.**
지평이 짧으면(L=5) 이 −0.018 손실을 이후 몇 스텝의 펌프-유지 이득(τ≈0.52~0.53)으로
곧 상각하는 편이 낫다고 판단하지만, **지평이 한 스텝 늘어나면(L=6) "한 스텝 더
버티고 그 다음에 전환해도 남은 창(window) 안에서 상각할 여유가 있다"는 판단이
성립**해 전환을 늦춘다. 액션 0의 τ=0.500은 **수위·저류량과 무관한 상수**이므로,
지평이 늘수록 "더 오래 버텨도 결국 상각된다"는 계산이 계속 성립해 **전환 시점이
계속 뒤로 밀리고, 그만큼 저류지가 더 채워진 뒤에야 펌프가 켜져 최고수위가 높아진다.**
목적함수에 수위·월류에 대한 직접 벌점이 없으므로 이 "대기의 기회비용"이 τ에
반영되지 않는다 — 이것이 R1-4가 지적한 괴리의 구체적 메커니즘이다.

### Task A (구현 공정성, R4-1)
- **A1** (미배치): GA-L·PSO-L이 ENUM-L보다 빨라지는 지점은 **L=3~5 사이** (L=5에서
  PSO 21×, GA 5.5× 빠름).
- **A2** (벡터화, 공정 비교): **PSO-벡터화는 L=3~5 사이**, **GA-벡터화는 L=5~6 사이**
  에서 ENUM-벡터화를 앞선다. L=8에서 GA 93×, PSO 1,021× 빠름.
- **A3**: 속도 역전 지점에서도 첫 액션 일치율은 0.83~1.00으로 높으나, τ_L gap은
  L과 함께 증가(mean 0.007~0.019 @L5 → 0.033~0.055 @L8, max 최대 0.58) — **속도
  이득에 측정 가능한 해 품질 비용이 따른다.**

### Task B (신가중치 포화, 270/18 표본)
- **B1**: argmin_L = **2 (다음 3)**. 구가중치의 L=6과 규모가 다르다(훨씬 작음).
- **B2**: **그렇다.** L=1(6.330 m) < L=8(부표본 n=18, 7.068 m). Wilcoxon L1 vs L8
  (n=18): p=3.8×10⁻⁵, **Cliff's δ=−0.889 (18개 중 17개에서 L8이 나쁨)**. L1 vs L7
  (n=18)도 p=2.5×10⁻⁴, δ=−0.753로 이미 역전.
- **B3**: 재현됨. 지속시간 60~360분→argmin=2, 1080~1440분→argmin=3.

### Task C (τ–목표 괴리, R1-4 — 이번 작업의 핵심 산출물)
- **cum_tau_L 단조성**: 270/270 시나리오에서 100% 엄격 증가(수학적 증명과 일치,
  버그 없음) — "τ는 완전열거이므로 반드시 개선"이 사실로 확인됨.
- **C1**: max_level 악화 비율 — **L2→3: 65.6%(n=270), L3→5: 98.9%(n=270),
  L5→6: 97.0%(n=270), L6→7: 94.4%(n=18), L7→8: 100.0%(n=18)** — 예외가 아니라
  지배적 패턴. (n=270 구간과 n=18 구간을 혼동하지 말 것.)
- **Spearman(cum_tau_L, max_level)**: L1 −0.36 → L3 −0.76(최강) → **L6 −0.03(소멸)**
  → **L7 +0.20, L8 +0.54(n=18, 부호 반전이 더 강해짐)** — τ 개선이 목표 개선을
  예측하는 힘이 지평과 함께 무너지고 L8에서는 완전히 반대로 돈다.
- **C2**(항 분해, 3사례 공통 메커니즘): 액션 0 유지는 `w2·act_reward+w3·energy
  =0.25+0.25=0.500`(상수, 수위 무관). 전환 순간은 스위칭 비용으로 τ≈0.48로
  일시 하락하나 이후 펌프-유지 구간에서 τ≈0.52~0.53으로 회복. **지평이 길수록
  "한 스텝 더 대기해도 남은 창에서 상각 가능"이 성립해 전환 시점이 계속 뒤로
  밀리고, 그만큼 저류지가 더 찬 뒤에야 펌프가 켜져 최고수위가 오른다.** 목적함수에
  수위·월류 직접 벌점이 없어 "대기의 기회비용"이 τ에 반영되지 않는 것이 근본 원인.
- **C3**: 지속시간과 직접 인과는 약함(L3→L5 악화가 전 지속시간·재현기간에 고르게
  분포). 다만 장기 시나리오일수록 argmin_L이 3까지 늦게 버티는 경향과는 연결.
